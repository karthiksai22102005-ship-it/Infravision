## 2. Verification limits (explicit)
Not available in this environment: Flutter/Dart SDK, Android SDK, SQL Server/ODBC, Inspector app, any physical device or emulator. Every claim about those is **UNVERIFIED**. Backend behaviour was verified on SQLite only, which differs from SQL Server in locking, collation, datetime and string types.

## 3. Architecture vs. required architecture
Matches: app talks only to the backend (no SQL credentials in app); server-generated reference; idempotency key; ownership checks return 404 on foreign records; magic-byte image check; private evidence dir; PDF hides inspector notes.
Deviates: Citizen uses its **own `citizen` schema/tables**, i.e. a disconnected complaint store, which the brief forbids unless the Inspector schema is unavailable (it is currently unavailable). PDFs are not stored. No document metadata table. No migration tooling beyond one hand-written SQL file.

## 4. Confirmed defects (reproduced or proven by reading code)
See `PRIORITIZED_MODIFICATION_PLAN.md` for IDs F-01..F-24. The most important:
- **F-04 (P1, reproduced):** a description containing `<` or `&` crashes PDF generation (`ValueError: Parse error`) because text goes unescaped into ReportLab markup. Any citizen can make their own report undownloadable.
- **F-05 (P1, code-proven):** ORM models have no schema, but the migration creates `citizen.*` tables. On SQL Server the app would query `dbo.citizens` and fail. The two sources of truth already disagree.
- **F-06 (P1, code-proven):** every complaint is first inserted with reference `"PENDING"` (unique). Two simultaneous submits by different users collide; the `IntegrityError` handler finds no idempotency record and re-raises, giving a 500. SQLite's single-writer lock hid this in tests.
- **F-07 (P1, reproduced):** Telugu cannot render in PDFs: the font file is not bundled, so `_font()` returned `Helvetica` in my run.
- **F-01 (P0):** `jwt_secret="CHANGE_ME"` and `inspector_api_key="CHANGE_ME_INSPECTOR"` are the defaults and nothing stops production starting with them (pytest even warns the HMAC key is 11 bytes).
